# CL3 作文批改教練

這是 CL3 極簡版作文批改網頁的程式碼。公開儲存庫不包含試算表 ID、後台網址或連線密碼；請勿把真實學生作文或個資提交到 GitHub。

## 資料夾裡有什麼

- `index.html`：網頁畫面；需要 AI 功能時，請用下方啟動檔開啟本機伺服器。
- `google-apps-script/Code.gs`：連接 Google 試算表的後台程式。

## 上傳到 GitHub

此專案已連接到 GitHub 儲存庫。修改後可透過 Git 提交並推送；若改用 GitHub 網頁上傳，請上傳資料夾內的原始檔案，不要直接上傳壓縮檔。公開儲存庫只保存程式碼與不含個資的範例資料。

## 重要提醒

請勿把試算表 ID 或連線密碼直接寫進程式碼。請在 Apps Script 的「專案設定 → 指令碼屬性」中建立 `SPREADSHEET_ID` 與 `ACCESS_KEY`，開啟網頁後再輸入部署網址和同一組連線密碼。

目前 Google Apps Script 已部署完成。只要後台程式沒有變更，不需要重新部署。

## 使用方式

### Windows 本機 AI 測試

1. 確認 Codex App／CLI 已用 ChatGPT 帳號登入。
2. 直接雙擊 `啟動網站.bat`（第一次會建立 `.venv`）；也可以用 PowerShell 執行 `啟動網站.ps1`。
3. 啟動完成後，瀏覽器會開啟 `http://127.0.0.1:8765`。請保持啟動視窗開啟；若瀏覽器未自動開啟，可手動輸入此網址。
4. 貼上作文後按「用 Codex 分析這篇作文」。本機後端會呼叫 Codex CLI，不需要在網站保存 API Key。

作文可在左側「原文」按「編輯原文」貼上或修改，也可以展開「作文基本資料與匯入」後按「匯入文章檔案」或拖放檔案。支援 UTF-8／Big5 的 TXT、Markdown 與 DOCX，單檔最大 5 MB、文章最多 20,000 字。按原文區下方「用 Codex 分析這篇作文」後，文章大意與錯字檢查會顯示在原文下方，文章大綱仍可由上方分頁查看。長作文、老師重點與 AI 評語欄位會隨內容自動增高，不會只顯示前半段。

匯入文章或按「清空並新增文章」會建立一筆新的批改草稿；若目前已有作文或批改內容，系統會先詢問是否取代。新草稿會清除上一份作文的 AI 結果、老師重點、評語與分數，但保留年級、教學目標和試算表連線設定。每篇作文的草稿使用不同識別碼儲存在瀏覽器中，避免前一篇內容殘留到新文章。

## 兩種 AI 模式

- **找點模式**：AI 發散可能的亮點、生命經驗與下一步，老師可把選定項目按「加入重點」。
- **評語豐富模式**：老師輸入條列、關鍵字或短句，選擇文體後，AI 只沿著老師指定的方向整理成三段自然評語。生成結果可以修改、複製，或套用到「我的評語」。

兩種模式共用同一篇作文、年級、題目與找點模式判斷出的文體，但使用不同 prompt 與 JSON Schema。`prompts.py` 管理兩種 prompt；`ai_schema.json` 是找點結果格式，`comment_schema.json` 是評語豐富結果格式。

## 國中會考作文評估

右側「會考寫作評估」是第三種獨立模式，畫面名稱為「AI 會考寫作參考評估」。請先把年級填為國中、國一／二／三或七／八／九年級，填入作文題目與原文，再按「評估這篇作文」。結果提供四面向的參考級距、結論、原文證據與判斷理由，接著顯示整篇參考級分、整體理由，以及唯一最值得優先改善的一件事。分項級距不會被平均成整體級分，也不會自動寫入「老師評分 /10」。正式會考一般為 1–6 級分；官方另列完全離題、只訂或抄寫題目／題幹、詩歌體、空白卷等 0 級分情況。這項結果供教練複核，並非正式會考閱卷成績。

評估依據是[國中教育會考寫作測驗官方評分規準](https://cap.rcpet.edu.tw/exam3-1.html)，設計參考[「AI 作文批改通用心法」簡報](https://docs.google.com/presentation/d/1OK8d7Gs2U8PL3Xn_mYrkMiNdlvW0cwFTkHxXnMvhzg8/edit)。若只輸入作文題名、未提供完整題幹，離題及材料運用判斷可能受限；貼入純文字也無法檢查手寫卷面與實際格式。使用前請移除學生姓名、班級等個資。

可用 `python -m unittest discover -s tests -v` 執行不耗 AI 用量的 prompt 契約測試。`tests/live_acceptance.py` 會實際呼叫 Codex 並消耗用量，只在需要完整驗收時執行。

這條路徑使用 Codex／ChatGPT 方案的 Codex 用量，適合本機單人測試；若未來公開部署，應改用 OpenAI API 與伺服器端 API Key。

如要連接試算表，另輸入 Google Apps Script 的 `/exec` 部署網址及連線密碼。按「儲存草稿」或「完成批改」時，資料會寫入指定試算表。
